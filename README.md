# Azure IAM Security Lab

This repository demonstrates identity and access management design
using Microsoft Entra ID, focusing on least privilege,
conditional access, and identity risk mitigation.

## Key Areas
- Identity modeling (users and groups)
- Role-based access control (RBAC)
- Conditional Access policy design
- Privileged account protection

## Tools Used
- Microsoft Entra ID
- Azure Portal
- Conditional Access (design-only)

## Key Security Concepts
- Least privilege
- Privileged access protection
- Identity-based attack mitigation
